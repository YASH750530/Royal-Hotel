# Royal Hotel Management System

A full-stack hotel booking web application designed to simplify room reservations and hotel administration.

## Features

* Hotel rooms and pricing display
* Online room booking form
* MySQL database integration
* Unique booking ID generation
* Admin login and authentication
* Admin dashboard for managing bookings
* Booking status management
* Deployed backend API

## Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Node.js, Express.js
* **Database:** MySQL (Aiven)
* **Authentication:** JWT, bcrypt
* **Deployment:** Render
* **Version Control:** Git, GitHub

## Local Setup

1. Clone the repository.
2. Install dependencies using `npm install`.
3. Create a `.env` file with the required environment variables.
4. Start the backend using the start script configured in `package.json`.

## Security

Never upload database credentials, API secrets, JWT secrets, or `.env` files to GitHub.
